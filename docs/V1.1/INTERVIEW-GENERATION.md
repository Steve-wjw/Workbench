# V1.1 资料生成面经

## 功能范围

资料详情页提供“生成面经”按钮。服务根据当前资料标题和正文生成最多三条面经草稿，用户确认后通过现有面经接口保存。

生成阶段不直接写入数据库，也不会自动创建题目。保存时沿用资料的模块和标签，掌握状态默认为“未开始”。

## 模型配置

Java API 使用 OpenAI 兼容的聊天接口，默认读取：

- `DEEPSEEK_API_KEY`
- `DEEPSEEK_BASE_URL`
- `DEEPSEEK_CHAT_MODEL`

未配置 API Key 时，页面显示明确的生成失败提示，不影响资料库和面经的其他功能。

## 标签推荐

添加面试题、手工资料或导入 Markdown 时，页面会把输入内容发送到本地 Java API。Java API 只在已有标签名称中进行大小写不敏感的文本匹配，按出现次数和标签使用次数排序，最多返回三个推荐项。

该推荐不调用外部模型，不创建新标签，用户仍需手动确认是否选择。
