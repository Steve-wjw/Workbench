# V1.1 AI 热点

## 范围

新增「AI 热点」导航，进入时查询北京时间今天、昨天的精选新闻。
今天按发布时间展示最新的最多 5 条；昨天按上游评分降序展示最热的最多 5 条，
评分相同则较新的优先。上游未提供评分时排在有评分的新闻后，按时间补充并明确提示；
这些条目不能视为真实热度排名。这里的热度采用来源评分，不代表全网阅读量。
列表展示标题、原文来源、发布时间、分类和概述预览；点击后展示完整概述、
关注理由（若有）、原文与 AIHOT 详情链接。概述直接使用 AIHOT 返回的内容，
本项目不额外生成或改写，不需要模型密钥。

不增加数据库表、持久化接口、定时任务、收藏或历史记录。
页面保持现有中性色、青绿色强调、细边框和紧凑布局。

## 接口与缓存

- `GET /api/v1/ai-news`：查询今天、昨天的新闻。
- `GET /api/v1/ai-news?refresh=true`：主动刷新，最短上游请求间隔为 1 分钟。
- 进程内只保留一份快照，缓存 10 分钟，重启即清空。
- 服务端合并并发刷新；源站有 ETag 时进行条件请求；遵守 `Retry-After`。
- 按北京时间的发布时间筛选、去重、排序，不用采集时间替代发布时间。
- 上游异常时，同一天的缓存可降级展示，并明确标注更新失败；跨日旧快照不冒充今天。
- 上游请求设置连接/读取超时，最多读取 3 页；部分截断时有提示。
- 前端离开页面会取消请求，单次加载最长等待 20 秒。
- 响应带 `Cache-Control: no-store`，不使用浏览器持久缓存。

## 数据来源

使用 AIHOT 的个人用途公开只读 API：

- 接口文档：`https://aihot.news/openapi-v1.json`
- 请求：`/api/v1/items?mode=selected&window=7d&by=published&limit=100`

页面保留 AIHOT 与原文出处。此接入用于个人本地阅读；若未来公开部署、
商用或扩展为对外新闻服务，需先重新确认数据源授权和使用规则。
数据源出现访问限制时显示失败提示及源站入口，不绕过访问限制，不伪造新闻。

## 运行与验证

前端启动方式不变，Java 新增接口需重启 API 服务后生效。
不需要数据库迁移或额外环境变量；需要本机网络能够访问 `aihot.news`。

```sh
npm --prefix frontend run build
mvn -f backend-java/pom.xml test
```

自动测试使用模拟上游响应，不访问外网或数据库，覆盖北京时间分组、全文保留、
去重、安全链接、排序上限、分页、缓存、刷新、ETag、跨日、错误降级和限流。

## 后端连接状态

顶部不再展示「本地模式」。侧栏独立请求 `GET /api/v1/health/live`，
初始显示「正在检测连接」，成功后显示「后端已连接」，失败或 4 秒超时则为「连接异常」。
可见页面每 30 秒检查一次，切回窗口、页面恢复可见和网络恢复时也会重新检查。
该接口只检查 Java API，不访问数据库或 Python；新闻源异常和业务校验错误不会改变连接状态。
原有 `/api/v1/health` 综合诊断接口保持不变。
