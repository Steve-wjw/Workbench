# 个人 AI 工作台 PRD v1

> 当前范围：2026-10-26 简化版。本文件取代早期包含 AI 查询和草稿审核的设计。

## 1. 定位与目标

面向个人 AI 学习和面试准备的本地 Web 工作台，集中管理资料和面试题。

核心流程：整理模块和标签 → 导入资料或录入题目 → 浏览、筛选、复习 → 持续编辑。

模块是学习主题的一级分类，例如“机器学习”；标签是跨主题的细粒度标记，例如“高频题”。一份资料或题目可属于一个模块，并拥有多个标签。

## 2. 页面与功能

| 页面 | 当前功能 | 交互边界 |
|---|---|---|
| 首页 | 资料数、面试题数、最近更新内容、索引失败提醒 | 不展示标签数、模块数或开发阶段说明 |
| AI 面经 | 手工新建、编辑、删除题目，按关键词、模块、标签、难度、掌握状态筛选 | “新建面试题”只出现在本页面 |
| 资料库 | 手工资料、Markdown 导入、搜索、阅读、编辑、归档、删除、重新索引 | 只保留一个导入入口，弹窗区分粘贴内容与选择文件 |
| 标签管理 | 创建、编辑、删除标签，查看使用次数 | 删除标签不删除资料和题目 |
| 模块管理 | 创建、查看、删除模块 | 删除模块后关联资料和题目变为未分类 |

顶部只保留刷新操作，不提供全局搜索、命令面板或跨页面新建快捷键。资料库与面经保留各自的关键词搜索。

## 3. 业务规则

- 面试题保存标题、问题、简短答案、详细解释、关键点、模块、标签、难度与掌握状态。
- 难度为简单、中等、困难；掌握状态为未开始、学习中、已掌握。
- 资料保留原文、规范化文本、来源、正文哈希、模块、标签和索引信息。
- 手工资料和 Markdown 导入保存后自动创建索引任务；重复 Markdown 内容复用未归档资料。
- 资料正文变化后重新索引；仅修改标题、模块、标签不必重建内容索引。
- 资料状态为待索引、索引中、已索引、失败、已归档，不再提供草稿状态。
- 用户只控制归档与恢复，不能手工将资料标记为已索引；索引结果由后台写入。
- 归档资料保留内容；恢复后排入索引。后台任务不能覆盖用户设置的归档状态。
- 删除资料清理资料标签、片段和对应任务，不删除正式面试题；原始上传副本不自动删除。
- 删除操作需要确认，页面没有撤销或回收站。

## 4. 非功能要求

- 本机单用户运行，不开放到公网；业务数据保存在 PostgreSQL 与本地目录。
- 本地配置保存在 `.env`，仅 `.env.example` 纳入版本管理。
- Java API 统一返回错误码、消息和请求 ID；失败操作在页面有可读提示。
- 索引失败记录原因和尝试次数；同一资料已有活跃任务时复用任务。
- 保持必要的类、方法和模型字段注释，变更配套测试与文档。

## 5. 当前不做

AI 草稿和审核环节已取消；AI 查询暂不开放，其闲置查询、问答、提炼和模型调用实现从当前代码清理。未来是否重新引入查询能力，需单独评估需求，不默认恢复草稿流程。

不包含多用户、云同步、外部模型配置页面、全局搜索、自动备份恢复、PPT 或视频生成。

## 6. 后续方向

优先评估批量导入、更多文件格式、复习队列、数据导出与备份恢复。Docker/Compose、Flyway、真正的语义向量模型和 AI 查询按后续需求独立立项，不增加当前运行依赖。
