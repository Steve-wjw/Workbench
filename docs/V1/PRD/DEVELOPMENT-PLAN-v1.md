# 个人 AI 工作台开发计划 v1

> 2026-10-26 简化后的维护基线。旧阶段编号保留用于理解实施历史，不再作为扩展功能的交付承诺。

## 1. 当前交付范围

| 原阶段 | 当前处理 |
|---|---|
| 阶段 0：初始化 | 保留 Maven、Python 3.14、本地 PostgreSQL、前端与启停脚本 |
| 阶段 1：业务基础 | 保留资料、题目、模块、标签管理和关联校验 |

## 2. 本轮简化

- 首页仅展示资料与面试题数量，去掉开发说明。
- 新建面试题只在 AI 面经中提供。
- 资料库保留一个导入入口，弹窗区分粘贴与上传。
- 取消草稿状态，新建资料自动排入索引；归档与索引状态分开维护。
- 清理未使用的前后端代码、配置模板与测试；不删除现存业务表或本地配置。
- 文档只维护 PRD、USER 和备份设计；阶段验证合并为 USER 下单一文件。
- 媒体清理目标：删除演示文稿、视频、生成脚本与中间缓存，不引入媒体制作依赖。遗留产物不参与业务构建。

## 3. 升级与验收

1. 停止本地服务并按备份设计备份数据库与上传文件。
2. 显式执行数据库初始化脚本，兼容旧草稿状态。
3. 运行 Java/Python 测试与前端构建。
4. 重启服务，按 [V1 验证说明](../USER/VERIFICATION-v1.md) 完成页面和表数据验收。

## 4. 后续候选项

优先按实际使用反馈评估批量管理、更多资料格式、复习队列、导出与备份恢复。
Docker/Compose 和 Flyway 留待后续版本。真正的语义检索及 AI 查询需重新明确业务价值后再设计，不自动恢复被取消的草稿环节。
