# AI 工作台 V1 使用指南

AI 工作台帮助你集中整理 AI 学习资料和面试题。你可以从一份 Markdown 资料或一道面试题开始，不需要先配置大模型。

## 1. 打开工作台

启动本地服务后，在浏览器打开 `http://localhost:5173`。
首页显示资料数、面试题数和最近更新的内容。点击左侧导航进入需要的页面；右上角刷新按钮可更新数据。

## 2. 整理模块和标签

模块像资料夹，用来划分学习主题，例如“机器学习基础”“大模型”。
标签像贴纸，适合标记跨主题内容，例如“高频题”“位置编码”。
一份资料或一道题目可以选择一个模块和多个标签，也可以暂时不分类。

在“模块管理”填写名称、Slug 和描述后保存。
Slug 是简短、稳定的标识，例如 `machine-learning`，建议使用小写英文和连字符。
在“标签管理”可以创建标签、选择颜色，也可以编辑或删除标签。

删除模块或标签不会删除资料、题目：前者变为未分类，后者移除对应标签。

## 3. 使用资料库

### 导入 Markdown

1. 打开“资料库”，点击右上方唯一的“导入 Markdown”按钮。
2. 在弹窗选择“粘贴内容”或“选择文件”；这是两种导入方式，不是两套业务流程。
3. 填写标题，粘贴正文或选择 `.md` / `.markdown` 文件。
4. 按需选择模块和标签，查看预览后提交。
5. 稍等片刻并刷新，查看索引结果。重复内容会打开已有的未归档资料。

也可以点击“手工资料”，直接填写标题和正文。保存后同样会自动开始后台处理。

### 阅读与维护

点击资料进入详情，可切换预览、原文和规范化文本；点击“编辑”修改内容。
资料库中的搜索框用于查找标题或正文。

| 状态 | 含义与处理 |
|---|---|
| 待索引 | 等待后台处理，可稍后刷新 |
| 索引中 | 正在处理 |
| 已索引 | 处理完成，可以继续阅读和维护 |
| 失败 | 打开详情查看原因，修正后重新索引 |
| 已归档 | 保留内容但暂时不使用，可在编辑中取消归档 |

当前不再使用草稿状态。索引状态由系统维护，你不需要手工选择。
归档后需要重新处理时，先取消编辑表单中的“已归档”，保存后等待索引。
索引失败不会删除原文。

点击删除图标并确认，可以删除资料及其索引记录；已创建的面试题保留。
上传时保留的文件副本不会自动从磁盘移除。

## 4. 维护 AI 面经

1. 打开“AI 面经”，点击“新建面试题”。
2. 填写标题和问题，按需补上简短答案、详细解释和关键点，每个关键点单独一行。
3. 选择模块、标签、难度和掌握状态并保存。
4. 复习时按关键词、模块、标签、难度或掌握状态筛选。
5. 点击编辑图标补充答案或更新掌握状态；不再需要的题目可删除。

“简短答案”适合写成面试时直接表达的版本，“详细解释”可记录原理和边界。
新建题目只在 AI 面经中提供，资料库专门维护学习资料。

## 5. 数据与常见问题

业务数据保存在本机 PostgreSQL；上传的 Markdown 副本位于项目 `data/imports/`，以 `.env` 中配置的数据目录为准。
粘贴或手工录入的正文直接保存在数据库，不一定存在同名磁盘文件。

删除没有撤销功能，重要内容应先备份，参见 [备份与导出设计](../../BACKUP-EXPORT-DESIGN.md)。

页面报错时先刷新；持续报错可查看 `data/logs/` 对应时间的日志及请求 ID。
资料一直待索引时应检查 Python worker，而不仅是浏览器或 Java API 是否启动。

当前版本没有 AI 查询、AI 草稿、AI 提炼或全局搜索入口。日常使用无需模型 API Key。
部署与升级参见 [运行说明](../PRD/README.md)，验收参见 [统一验证说明](VERIFICATION-v1.md)。
