# AI 工作台 V1 使用指南

AI 工作台帮助你集中整理 AI 学习资料和面试题。你可以从一份 Markdown 资料或一道面试题开始，不需要先配置大模型。

## 1. 打开工作台

启动本地服务后，在浏览器打开 `http://localhost:5173`。
首页显示资料数、面试题数、按 ID 排序的面试题和最近更新的资料。点击左侧导航进入需要的页面；右上角刷新按钮可更新数据。

刷新浏览器会保留当前标签页所在的模块和已打开的题目、资料或热点详情，不再固定回到首页。详情会重新从服务端加载；内容已删除、热点已过期或详情获取失败时回到对应模块的列表。浏览器只记录页面位置和内容 ID，不缓存正文或未保存的表单；关闭标签页后不保证恢复，禁用浏览器存储时仍可正常使用。

## 2. 整理模块和标签

模块像资料夹，用来划分学习主题，例如“机器学习基础”“大模型”。
标签像贴纸，适合标记跨主题内容，例如“高频题”“位置编码”。
一份资料或一道题目可以选择一个模块和多个标签，也可以暂时不分类。

在“模块管理”填写名称和描述后保存。
在“标签管理”可以创建标签、选择颜色，也可以编辑或删除标签。
在新建面试题、手工资料或导入 Markdown 时，也可以直接创建模块和标签；输入内容后，系统会从已有标签中推荐最多三个相关标签供选择。

删除模块或标签不会删除资料、题目：前者变为未分类，后者移除对应标签。

## 3. 使用资料库

### 导入 Markdown

1. 打开“资料库”，点击右上方唯一的“导入 Markdown”按钮。
2. 在弹窗选择“粘贴内容”或“选择文件”；这是两种导入方式，不是两套业务流程。
3. 填写标题，粘贴正文或选择 `.md` / `.markdown` 文件。
4. 按需选择模块和标签，查看预览后提交。
5. 稍等片刻并刷新，查看索引结果。重复内容会打开已有的未归档资料。

也可以点击“手工资料”，直接填写标题和正文。保存后同样会自动开始后台处理。

### 阅读与维护

点击资料进入详情，可切换预览、原文和规范化文本；点击“编辑”修改内容。
资料库中的搜索框用于查找标题或正文。
打开资料详情后，可以点击“生成面经”。系统会根据资料生成最多三条待确认草稿，确认后才会保存到 AI 面经。

| 状态 | 含义与处理 |
|---|---|
| 待索引 | 等待后台处理，可稍后刷新 |
| 索引中 | 正在处理 |
| 已索引 | 处理完成，可以继续阅读和维护 |
| 失败 | 打开详情查看原因，修正后重新索引 |
| 已归档 | 保留内容但暂时不使用，可在编辑中取消归档 |

当前不再使用草稿状态。索引状态由系统维护，你不需要手工选择。
归档后需要重新处理时，先取消编辑表单中的“已归档”，保存后等待索引。
索引失败不会删除原文。

点击删除图标并确认，可以删除资料及其索引记录；已创建的面试题保留。
上传时保留的文件副本不会自动从磁盘移除。

## 4. 维护 AI 面经

1. 打开“AI 面经”，点击“新建面试题”。
2. 填写问题和答案，详细解释可以按需补充。
3. 选择模块、标签、难度和掌握状态并保存。
4. 复习时按关键词、模块、标签、难度或掌握状态筛选。
5. 点击编辑图标补充答案或更新掌握状态；不再需要的题目可删除。

题目列表按自增主键 ID 升序展示，修改答案或掌握状态不会改变题目位置。列表展示问题、分类信息，以及缩进的追问标题，不展示答案。点击题目进入详情，可查看答案、详细解释，并切换 Markdown 预览和原文；首页题目也可以直接打开详情。

旧数据库升级时，先备份并停止业务写入，完整执行 [面试题自增主键迁移 SQL](../../V1.1/QUESTION-ID-IDENTITY-MIGRATION.sql)，再重启更新后的 Java API。迁移保留题目内容和标签关系，不额外保留 UUID 或题号字段；旧 UUID 详情地址失效。升级步骤和编号规则见 [自增主键说明](../../V1.1/QUESTION-ID-IDENTITY.md)。

在“追问面试题”右侧点击“+”，分别填写“追问”和“回答”。两项均支持 Markdown，可添加多条，也可以逐条编辑、删除；平时只显示排版后的问答内容，不显示输入框。详情页的“预览 / 原文”切换同样适用于追问和回答，列表仅展示每条追问的首行标题。

新建、编辑主问题时，添加的追问随主问题一起保存；在详情页添加、编辑或删除追问会直接保存。旧版合并 Markdown 追问会兼容显示，原有正文和代码块不会丢弃。现有数据库若尚未添加追问字段，先执行 [追问字段迁移 SQL](../../V1.1/QUESTION-FOLLOW-UPS-MIGRATION.sql)，再重启 Java 后端；本次交互调整不再新增字段。

追问复用 `follow_up_questions` 文本字段，新数据保存为 `{"version":1,"items":[{"question":"追问 Markdown","answer":"回答 Markdown"}]}`，旧 Markdown 在读取时兼容转换，只有修改追问时才会写回结构化内容；删除最后一条追问时保存空字符串。

“简短答案”适合写成面试时直接表达的版本，“详细解释”可记录原理和边界。
新建题目只在 AI 面经中提供，资料库专门维护学习资料。

## 5. 数据与常见问题

业务数据保存在本机 PostgreSQL；上传的 Markdown 副本位于项目 `data/imports/`，以 `.env` 中配置的数据目录为准。
粘贴或手工录入的正文直接保存在数据库，不一定存在同名磁盘文件。

删除没有撤销功能，重要内容应先备份，参见 [备份与导出设计](../../BACKUP-EXPORT-DESIGN.md)。

页面报错时先刷新；持续报错可查看 `data/logs/` 对应时间的日志及请求 ID。
资料一直待索引时应检查 Python worker，而不仅是浏览器或 Java API 是否启动。

当前版本没有 AI 查询或全局搜索入口。生成面经功能需要配置兼容的模型 API Key；生成结果在确认前不会写入数据库。
部署与升级参见 [运行说明](../PRD/README.md)，验收参见 [统一验证说明](VERIFICATION-v1.md)。
