# AI 工作台 V1 产品概览

> 2026-10-26 简化版，面向个人本地使用。

## 核心价值

把分散的 AI 学习资料和面试题集中管理，用模块和标签整理，用难度和掌握状态安排复习，持续积累自己的答案。

## 当前功能

| 功能 | 带来的价值 |
|---|---|
| Markdown 粘贴、文件导入与手工资料 | 统一保存学习资料，保留原文与预览 |
| AI 面经手工维护 | 问题、答案、关键点和复习状态集中管理 |
| 模块与标签 | 按主题分类，也能跨主题筛选 |
| 资料后台索引与重试 | 清楚了解处理结果，失败时原文仍在 |
| 分页 API、页面关键词搜索和筛选 | 查找已有内容，减少反复翻找文件 |
| 本地优先 | 当前功能不依赖外部大模型或云端服务 |

首页仅保留资料数、面试题数和最近内容。新建题目归属于 AI 面经；资料库只有一个 Markdown 导入入口，不再提供草稿状态或全局搜索。

## 核心技术

React + TypeScript + Vite 提供界面，Java 21 + Spring Boot + Maven 负责业务和数据一致性，
Python 3.14 + FastAPI/worker 负责资料解析与索引，PostgreSQL 16 + pgvector 保存业务数据和片段。

当前索引向量是离线确定性哈希向量，不是真正的语义模型。页面使用关键词和业务条件筛选。
所有服务以本机进程运行，不需要 Docker、Redis 或消息队列。

## V2 优化方向

优先改进批量导入与整理、更多文件格式、复习队列、导出和备份恢复。
有明确使用需求后再评估语义检索和 AI 查询，不增加草稿审核这一步。
容器化与 Flyway 留待后续版本，不构成 V1 的部署前提。

## 版本边界

AI 草稿流程取消，AI 查询暂不开放；相关闲置后端实现已从当前工程移除。
旧数据库中的历史表和原有 `.env` 保留，避免清理代码时误删数据或本地配置。
多用户、云同步、公开分享与演示媒体生成不属于当前版本。
