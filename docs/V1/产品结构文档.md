# AI 工作台 V1 产品结构文档

版本：V1 / 1.0.0。基准日期：2026-11-19。本文描述当前页面和业务结构，不是未来路线图。

## 1. 导航结构

```text
AI 工作台
├── 内容
│   ├── 首页
│   ├── AI 热点
│   │   ├── 今天 / 昨天列表
│   │   └── 新闻详情 → 原文 / AIHOT 详情
│   ├── AI 面经
│   │   ├── 列表与筛选
│   │   ├── 新建 / 编辑面试题弹窗
│   │   └── 题目详情 → 答案 / 解释 / 多条追问
│   ├── 资料库
│   │   ├── 列表与关键词搜索
│   │   ├── 手工资料弹窗
│   │   ├── 导入 Markdown 弹窗 → 粘贴 / 文件
│   │   └── 资料详情
│   │       ├── 预览 / 原文 / 规范化文本
│   │       ├── 任务历史 / 重新索引
│   │       └── 生成面经 → 结果确认 → 保存到 AI 面经
│   └── GitHub
│       ├── 自研
│       ├── 开源
│       ├── 新增 / 编辑项目弹窗
│       └── 项目详情 → 概况 / 个人备注 / 仓库链接
└── 管理
    ├── 标签管理 → 新建 / 编辑 / 删除
    └── 模块管理 → 新建 / 删除
```

## 2. 页面职责

| 页面 | 核心内容 | 主要动作 | 不承担的职责 |
| --- | --- | --- | --- |
| 首页 | 资料与题目数量、各 5 条摘要入口 | 进入模块、打开题目详情 | 不创建题目，不提供全局搜索 |
| AI 热点列表 | 今天、昨天的新闻与概述预览 | 刷新、打开新闻详情 | 不收藏、不落库、不生成题目 |
| AI 热点详情 | 完整概述、理由、原文出处 | 返回列表、打开外链 | 不编辑新闻 |
| AI 面经列表 | 问题、追问标题、状态、来源、标签 | 搜索筛选、新建、编辑、删除、进入详情 | 不在列表展开答案 |
| 面试题详情 | 主问题、答案、解释、追问问答 | 预览/原文、编辑、管理追问、删除 | 不执行 AI 评估 |
| 资料列表 | 标题、来源、索引状态、更新时间 | 搜索、新建、导入、打开详情 | 不承担面试题新建入口 |
| 资料详情 | 原文及规范化结果、任务历史 | 阅读、修改、归档、重建索引、生成面经 | 不自动把生成结果入库 |
| GitHub 列表 | 分类数量、项目概况、同步状态 | 分类、搜索、翻页、新增、同步、编辑、删除 | 不读源码、不操作远程账号 |
| GitHub 详情 | 概况、地址、Markdown 备注 | 外链、同步、修改备注/分类 | 不存完整 README |
| 标签管理 | 标签名称、颜色、使用量 | 新建、编辑、删除 | 不提供完整标签树维护 |
| 模块管理 | 模块名称、描述、状态 | 新建、删除 | 当前无页面编辑入口 |

## 3. 核心对象关系

```text
模块 ──< 资料 >──< 标签
模块 ──< 面试题 >──< 标签
资料 ──< 索引任务
资料 ──< 资料片段（含本地哈希向量）
面试题 ── 追问集合（题目字段中的结构化文本，不是独立表）
GitHub 项目 ── 分类：自研 / 开源（独立于模块和标签）
AI 热点 ── 服务进程内临时快照（无业务表）
```

资料生成面经是内容流转而非持久化血缘关系：当前题目只记录 `DOCUMENT` 来源类别，没有新增指向原资料的来源外键或可回溯入口。删除资料不会删除已经保存的题目。

## 4. 主要用户路径

### 路径一：学习资料整理

进入资料库 → 粘贴或上传 Markdown / 手工录入 → 选择或新建模块、标签 → 保存 → 后台索引 → 阅读预览及规范化文本 → 按需维护或重新索引。

### 路径二：面试复习

进入 AI 面经 → 新建主问题与答案 → 设置难度、掌握状态、分类 → 通过“+”补充追问 → 保存 → 列表查看问题层级 → 打开详情复习 → 更新掌握状态。

### 路径三：资料辅助转题目

打开资料详情 → 生成面经 → 查看最多 3 条结果 → 确认保存 → 在 AI 面经查看“资料库生成”来源题目。生成失败不影响原资料；保存中途失败应先检查已保存结果。

### 路径四：快速阅读热点

进入 AI 热点 → 获取或命中临时缓存 → 浏览今天/昨天各最多 5 条 → 点击详情阅读完整概述 → 按需打开原文。上游失败走错误提示或同日快照降级。

### 路径五：项目积累

进入 GitHub → 选择自研/开源 → 新增公开仓库地址 → 获取概况或保存待同步地址 → 写个人备注 → 后续搜索、手动同步或打开 GitHub。

## 5. 共用交互

- 内容录入中的模块“+”和标签“新建”复用分类创建能力，分类会独立保存，不随取消主表单自动撤销。
- 标签推荐是可选辅助项，用户显式选择才关联；异常不能冒充已选择标签。
- Markdown 预览与原文使用一致的阅读方式；资料另外提供规范化文本，题目不需要该额外选项。
- 刷新按钮按当前模块更新数据；GitHub 页面刷新读取本地列表，不等于逐个同步远程仓库。
- 同一浏览器标签页记住页面位置及详情标识，不保存未提交表单和所有筛选状态。
- 侧栏连接状态只检查 Java API；业务错误在对应页面独立显示。
