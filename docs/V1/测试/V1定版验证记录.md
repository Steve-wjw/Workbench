SQL 集成测试首次在沙箱内被共享内存权限阻止；经许可在沙箱外启动临时 PostgreSQL。主键测试随后发现套接字路径超过 macOS 103 字节限制，缩短临时目录前缀后两组全部通过。测试通过独立 Unix socket 连接临时集群，不读取业务 `.env`，测试结束关闭实例。

本机测试 PostgreSQL 为 Homebrew 18.6，以上结果不是 PostgreSQL 16 上的专项兼容验证。部署基线仍以现有项目约定的 PostgreSQL 16 + pgvector 为准。

第二批 SQL 本次做内嵌 JSON 数量及搬移一致性检查；此前已经在独立库验证 15 道主问题、46 道追问、42 条标签关联、复用和回滚，本次没有对业务库重导入。
