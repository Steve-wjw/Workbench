# AI 工作台 V1 用户使用说明

## 1. 进入工作台

启动本地服务后打开 `http://localhost:5173`。左侧包括首页、AI 热点、AI 面经、资料库、GitHub、标签管理、模块管理。部署步骤见 [本地部署与配置说明](本地部署与配置说明.md)。

首页显示资料数、面试题数、前 5 道按 ID 排序的题目，以及最近更新的资料。点击题目可进入详情。

同一浏览器标签页刷新会恢复当前页面、打开的内容和 GitHub 分类，不再固定回首页。未保存表单、正文和全部筛选项不会恢复；内容删除或详情失效时回对应列表。

“后端已连接”只表示 Java API 可达，不代表数据库、Python worker 或外部新闻、模型、GitHub 都正常。

## 2. 模块和标签

模块像主题文件夹，例如 Agent、RAG；标签像跨主题标记，例如 MCP、高频题。每份资料或题目可选择一个模块、多个标签，也可暂时未分类。

- 模块管理：填写名称、描述后新建，可删除；当前页面没有编辑模块的入口。
- 标签管理：创建名称和颜色，可编辑、删除。
- 新建/编辑面试题、手工资料及导入 Markdown 时，可就地新建模块和标签；成功创建的分类会独立保留，即使后来取消内容表单也不会自动撤销。
- 删除模块不删除资料和题目，只变为未分类；删除标签仅移除对应关联。

内容推荐原本用于从已有标签中提供最多 3 个候选，不是 AI 自动打标。当前版本存在推荐接口分页问题，未出现候选时请手动选择或新建，不影响自行维护标签。

## 3. 资料库

### 新建或导入

手工整理：点击“手工资料”，填写标题和正文，选择分类后保存。正文支持 Markdown。

导入现成文档：

1. 点击工具栏“导入 Markdown”。
2. 选择粘贴内容或选择文件；文件使用 `.md`/`.markdown`。
3. 填写或核对标题，选择模块、标签，查看预览。
4. 提交后等待处理，稍后刷新。

相同正文的未归档 Markdown 导入会打开已有资料，避免重复。手工新建不保证相同内容自动合并。导入到资料库保存的是一份资料，不会自动把二级标题拆成多道面试题；文档转题目批量导入见 SQL 说明。

### 阅读和维护

详情提供“预览”“原文”“规范化文本”。前两项用于阅读排版与原始 Markdown，规范化文本由后台处理生成，不是模型概述。

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| 待索引 | 等待 worker | 稍后刷新，长时间不变检查 worker |
| 索引中 | 正在处理 | 等待完成 |
| 已索引 | 规范化、切片和本地向量已完成 | 可阅读和维护 |
| 失败 | 后台处理异常 | 查看错误和任务记录，修正后重新索引 |
| 已归档 | 保留内容但暂不参与正常处理 | 编辑取消归档并保存后恢复处理 |

编辑正文会触发后续处理；“重新索引”可重建处理结果，不会调用聊天模型。关键词搜索覆盖当前加载的资料；当前页面主要加载前 100 条，超过时不保证通过页面搜索到所有历史资料。

删除需确认，会清理资料记录、标签关联、索引任务和片段，但不删除已保存题目；上传文件副本也不会自动从磁盘删除。

## 4. 从资料生成面经

打开资料详情点击“生成面经”。需先配置模型 API Key，并能访问对应模型服务。

一次生成最多 3 道，先显示待确认结果，未确认不入库。确认保存后沿用资料的模块、标签，掌握状态为未开始，来源为“资料库生成”。

请先核对问题和答案；长文仅使用前 14,000 个字符，不保证涵盖全文。关闭结果弹窗不会保存。当前确认是逐题保存，中途报错时先到 AI 面经核对已保存题目，避免重复点击导致重复录入。

“资料库生成”只记录创建方式，当前没有“跳转原资料”的绑定关系。删除原资料不会删除这些题目。

## 5. AI 面经与追问

1. 点击“新建面试题”，填写问题、答案，按需补充详细解释。
2. 选择模块、难度、掌握状态和标签。手工新建默认中等、未开始；导入 SQL 默认简单。
3. 在“追问面试题”右侧点击“+”，分别填写追问和回答，可添加多条。
4. 保存后在列表查看主问题及下一级追问标题；点击进入详情查看答案。
5. 详情中切换“预览/原文”，阅读主问题、答案、解释和追问的 Markdown。

详情中的追问可直接新增、编辑、删除，操作保存后立即写库；在主问题表单中编辑追问，则随主表单保存。离开未保存追问时请留意确认提示。

列表按自增 ID 升序，修改答案或掌握状态不改变顺序。ID 用于标识和排序，删除后有空号正常，不会重新连续编号。

可按关键词、模块、标签、难度、掌握状态筛选；列表不直接显示答案。当前筛选针对已加载的前 100 条，不是全库分页搜索。

来源显示“手动增加”或“资料库生成”，由创建入口记录，编辑不改变；历史题目默认手动增加。手工新增、维护和文件 SQL 导入都不会逐题调用 AI。

## 6. AI 热点

进入模块读取北京时间今天和昨天的新闻，今天展示最新最多 5 条，昨天展示来源评分最高最多 5 条；缺少评分会提示按时间补充，不是全网热度榜。

点击标题进入详情阅读完整概述，按需打开原文。概述来自 AIHOT，页面保留来源；当前不收藏、不存新闻表、不维护历史档案。

进程内缓存 10 分钟，成功刷新后至少间隔 1 分钟。临时网络失败时后端自动重试，每页最多尝试 3 次，整次查询最多等待约 15 秒。重试后仍失败，通常可在 15 秒冷却结束后再刷新；遇到上游限流则需等待更久，权限、证书或数据格式错误不会立即重试。短时间反复点击不会强制请求上游。更新失败时可能显示同日旧内容和警告；没有可用缓存时显示错误和源站入口。

出现“暂时无法获取 AI 热点”说明请求或解析失败，不代表当天无新闻。检查网络、Java 使用的代理、上游是否限流；侧栏显示后端已连接仍可能发生外网请求失败。

## 7. GitHub 项目

### 新增

1. 在 GitHub 选择“自研”或“开源”。前者记录个人开发上传的项目，后者记录想学习研究的公开仓库。
2. 点击“新增项目”，填写完整仓库根地址，例如 `https://github.com/owner/repository`，不要粘贴某个文件或 Issue 页面。
3. 可点击“获取概况”预览，也可直接保存。
4. 按需填写 Markdown 个人备注。

同一分类不可重复添加，两类可以各保存一次。分类由自己决定，不根据作者自动判断。

### 浏览和同步

列表支持按仓库名、简介、备注搜索及翻页。详情展示简介、主要语言、Stars、Forks、Topics、是否归档、最近推送、备注和仓库链接。

“同步概况”请求 GitHub 更新元数据；顶部“刷新数据”只刷新本地列表，不批量同步全部仓库。编辑可以改分类和备注，不会修改远程仓库；删除只删工作台中的记录。

| 状态 | 含义 |
| --- | --- |
| PENDING | 已保存地址，但尚未成功获取概况 |
| SUCCESS | 最近同步成功，或条件请求确认未变化 |
| FAILED | 同步失败，保留以前的成功概况及个人备注 |

失败后可稍后手动同步；限流时按上游等待，不要靠连续点击或重启绕过。可在后端配置 GITHUB_TOKEN 辅助公开仓库访问，但不等于免限额，也不启用私有仓库管理。

V1 不提供 GitHub 登录、Star 自动同步、README 全文缓存、源码下载或项目 AI 分析。

## 8. 数据保护和故障处理

业务数据在 PostgreSQL，上传 Markdown 副本在实际 `WORKBENCH_DATA_DIR/imports/`，粘贴/手工内容不保证有磁盘文件。删除没有撤销，重要内容先备份，见 [数据备份与恢复说明](数据备份与恢复说明.md)。

| 现象 | 优先检查 |
| --- | --- |
| 连接异常 | Java 是否启动、前端 API 地址是否正确 |
| 后端已连接但业务失败 | 数据库及迁移状态，错误请求 ID |
| 资料一直待索引 | Python worker、数据库连接与任务日志 |
| 生成面经失败 | 模型配置、网络代理、返回格式；未配置模型不影响手工录入 |
| 热点失败 | AIHOT 连通性及限流、Java 代理 |
| GitHub 获取失败 | 地址、公开性、额度、Token 或网络；已有备注不应丢失 |
| 浏览器刷新丢失表单 | 未保存输入不在恢复范围内 |

日志默认位于 `data/logs/`；反馈错误时提供时间和请求 ID，勿粘贴密码、Token 或完整 `.env`。

批量导入面试题及旧库升级见 [数据库脚本使用说明](SQL/数据库脚本使用说明.md)，不要把所有 SQL 无差别重跑。
