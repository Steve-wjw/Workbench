## 一句话定义

V2 将 AI 工作台从“本地资料与面试题管理工具”升级为“以个人知识资产为基础、以检索和复习为核心、AI 可选增强的学习执行系统”。

## 版本原则

1. **先完成学习闭环，再扩大 AI 范围**：资料导入、检索、复习、反馈必须先形成稳定链路。
2. **本地优先，AI 可插拔**：没有模型配置时，资料管理、关键词检索、复习和导出仍然可用。
3. **正式内容与生成内容分离**：AI 输出默认是候选内容，必须保留来源和用户确认边界。
4. **所有后台任务可观测、可重试、可恢复**：导入、解析、索引、导出和 AI 任务统一采用异步任务模型。
5. **V2 不默认扩张到多用户和云协作**：这不是当前单用户本地产品的主要矛盾。
