# 个人 AI 工作台 PRD v2

## 1. 产品目标

V2 的目标是让用户围绕自己的资料和面试题完成一个可重复的学习循环：

```text
收集 -> 整理 -> 检索 -> 练习 -> 反馈 -> 再复习
```

V2 不是把 V1 改成聊天机器人，而是把 V1 已有的资料资产和题库能力连接起来。

## 2. 用户与核心场景

### 2.1 目标用户

个人 AI 学习者、面试准备者和需要长期维护技术笔记的工程师。用户接受本地部署，重视数据所有权，不希望基础功能依赖云端模型。

### 2.2 高频场景

| 场景 | 用户需要 |
|---|---|
| 整理一批新资料 | 一次选择多个文件，预览解析结果，处理重复和失败项 |
| 准备一个主题 | 搜索资料、题目和原文片段，按模块和标签聚合 |
| 每日复习 | 直接看到今天到期的题目，答题后记录反馈 |
| 从资料出题 | 从选中的章节生成候选题，并确认后加入题库 |
| 校验答案 | 看到答案对应的资料来源，并获得缺失点建议 |
| 更换设备或保护数据 | 一键导出或创建备份，必要时恢复 |

## 3. 功能范围

### 3.1 P0：规模化内容管理

#### 批量导入

- 支持选择多个文件和本地目录。
- V2.0 首批格式：Markdown、纯文本、HTML、PDF。
- 每个文件展示：文件名、标题预览、识别格式、大小、重复状态、解析状态。
- 支持批次级取消未开始任务，单文件重试。
- 导入完成后生成资料记录和索引任务，保留原始文件。

#### 去重与冲突

- 使用正文规范化后的 SHA-256 作为默认去重键，同时保留原始文件哈希。
- 未归档资料重复时默认复用原资料；用户可以选择更新元数据或另存为新资料。
- 归档资料不作为默认复用对象，但在导入预览中明确提示可能重复。
- 同一批次内的重复文件只保留一个实际解析任务。

#### 列表与批量操作

- 资料、面试题、模块和标签改为服务端分页。
- 搜索、过滤、排序条件通过 URL 状态或显式请求保存。
- 支持批量归档、批量加标签、批量移动模块和批量重试索引。
- 失败任务、待索引任务、待复习任务提供独立入口。

### 3.2 P0：统一搜索

新增全局搜索页，但保留资料库和 AI 面经的上下文筛选。

搜索范围：

- 资料标题、正文、规范化文本、章节片段。
- 面试题标题、问题、答案和关键点。
- 模块和标签。

搜索结果：

- 结果类型、标题、摘要、模块、标签。
- 资料片段的章节路径和来源文件。
- 关键词命中、语义相似或两者兼有的标识。
- 点击后进入详情并定位到对应内容。

过滤项：

- 资料/面试题/片段。
- 模块、标签、来源类型。
- 资料索引状态、题目难度、复习状态。

### 3.3 P0：今日复习

#### 复习卡片

每道正式面试题最多对应一张复习卡片：

- `dueAt`：下次到期时间。
- 调度状态：新卡、学习中、复习中、暂停。
- 调度算法状态：由 FSRS 兼容实现维护。
- 最近一次复习时间、复习次数和连续正确次数。

#### 复习流程

1. 进入“今日复习”。
2. 显示题目，不默认显示答案。
3. 用户思考后点击查看答案。
4. 选择“忘记、困难、一般、简单、很简单”。
5. 写入复习记录，更新下次到期时间。
6. 进入下一题或结束本次复习。

#### 现有字段兼容

- 继续返回 `masteryStatus`，作为 UI 汇总状态。
- 由复习行为同步更新：无记录为 `NOT_STARTED`，有活跃复习为 `LEARNING`，连续达到规则后为 `MASTERED`。
- 不直接删除现有字段，避免 V1 数据和接口一次性破坏。

### 3.4 P1：来源与知识关联

- 资料片段可以关联面试题。
- 面试题详情展示支持来源、来源章节和最近引用。
- 资料删除时不删除题目；来源标记为失效，并允许重新关联。
- 题目可以有多个来源，资料也可以支持多个题目。
- 每个 AI 生成的候选题保留生成批次、提示版本和来源片段。

### 3.5 P1：有来源的 AI 辅助

AI 入口包含四类操作：

| 操作 | 输入 | 输出 | 是否自动写入正式内容 |
|---|---|---|---|
| 资料问答 | 问题 + 搜索范围 | 带引用的回答 | 否 |
| 生成候选题 | 资料或章节 | 一组候选题 | 否 |
| 检查答案 | 题目答案 + 来源范围 | 缺失点和风险提示 | 否 |
| 提炼关键点 | 选中的资料片段 | 关键点/术语候选 | 否 |

所有输出必须展示：

- 使用的资料片段。
- 模型与生成时间。
- 结果状态：候选、已接受、已拒绝。
- 用户修改记录或最终内容。

### 3.6 P1：导出、备份和恢复

#### 导出

- 资料导出为 Markdown。
- 面试题导出为 JSON 和 Markdown。
- 全部正式内容导出为 ZIP，包含清单、模块、标签、资料、题目、来源关系和复习数据。

#### 备份

- 备份包包含 PostgreSQL 数据和 `WORKBENCH_DATA_DIR/imports/` 原始文件。
- 备份包有版本号、创建时间、文件清单、大小和 SHA-256。
- 备份任务异步执行，失败时保留错误原因。

#### 恢复

- 恢复前校验格式、版本、校验和和目标数据库。
- 恢复前自动生成当前数据保护性备份。
- 恢复需要二次确认，不允许通过普通页面加载自动触发。
- 恢复后执行索引一致性检查，缺失索引任务自动补建。

## 4. 非功能要求

- V1 的资料、面试题、模块、标签和历史任务数据必须可升级。
- 所有长任务都不能阻塞 HTTP 请求线程。
- 任务至少支持幂等、状态查询、错误摘要和有限重试。
- 搜索不可用时，资料和题目 CRUD、关键词检索和复习仍可用。
- AI 未配置时，前端不展示不可用的强制入口。
- 导出、日志、API 响应不得包含密码、API Key、绝对路径或数据库连接字符串。
- 关键操作写入本地审计日志：导出、恢复、接受 AI 结果、批量删除和批量修改。

## 5. 版本分层

### V2.0 必须交付

- 服务端分页和统一搜索。
- 批量导入 Markdown/文本/HTML/PDF。
- 导入批次状态和失败重试。
- 今日复习、复习记录和 FSRS 兼容调度。
- 资料与题目的来源关联。
- JSON/Markdown 导出和可校验备份。

### V2.1 建议交付

- 真实本地或可选外部 Embedding Provider。
- 混合检索的语义排序。
- 带引用的资料问答。
- 根据资料生成候选面试题和答案检查。

### V2 后续评估

- DOCX、网页收藏和浏览器扩展。
- 移动端或桌面壳。
- 云同步、多设备冲突合并、多用户协作。

## 6. 明确不做

- 不恢复强制的 AI 草稿审核状态机。
- 不允许 AI 直接覆盖用户的正式资料或正式答案。
- 不把“启用外部模型”设为基础功能前置条件。
- 不在 V2 内同时解决多用户权限和云端部署。
